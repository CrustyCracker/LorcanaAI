# Ch'Nordcana Days 4 — Item hate / item removal techs

Źródło list: [Lorcanahunter — Ch'Nordcana Days 4](https://lorcanahunter.com/tournament/17188/hopopop-ch-nordcana-days-4) (inkDecks: [tournament 364400](https://inkdecks.com/lorcana-tournaments/ch-nordcana-days-4-tournament-decks-364400) — pojedyncze decki zablokowane przez Cloudflare).

## Zakres danych

- **Field size (gracze):** 128
- **Decklisty przeanalizowane:** 50
- **Definicja item hate/tech:** (1) karty celujące w itemy przeciwnika (banish / return / inkwell / lock / tax); (2) **discard z ręki kart non-character** (m.in. **Mowgli - Man Cub**, **Elisa Maza - Hardworking Detective**). Wykluczone: synergie „gdy grasz item” oraz banish własnego itemu jako koszt.
- **Uwaga źródłowa:** inkDecks publikuje ~64 listy tego eventu, ale pojedyncze strony decków zwracają Cloudflare 403 z tej maszyny; raport oparty o listy z Lorcanahunter (50 pełnych decków z publicznymi listami).

## Podsumowanie

- Gracze z ≥1 kartą item hate: **27 / 50** list (~54%)
- Najwięcej adoption: **Aladdin - Doing His Part** (8 talii / 16 kopii), **Elisa Maza - Hardworking Detective** (7 talii / 28 kopii), **Mowgli - Man Cub** (7 talii / 24 kopii)
- **Hand discard (non-character) w fieldzie:**
  - Elisa Maza - Hardworking Detective: 7 talii / 28 kopii
  - Mowgli - Man Cub: 7 talii / 24 kopii
  - Timon - Snowball Swiper: 1 talii / 3 kopii
